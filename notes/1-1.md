# 1-1 最小 `chat()`：把一句話送給模型、拿回一句話

> 完成於 commit `b2b4783`。

## 情境

agent 說穿了就是一個 `while` 迴圈：

```
把對話送給模型 → 模型說要用哪個工具 → 程式幫它跑 → 結果塞回對話 → 再送
```

那個「對話」是一個 list，list 就是 agent 的**全部記憶**——模型本身不記得任何事，每次都是把整包對話重新看一遍。

所以第一步是打通最底層的一件事：寫一個 `chat(messages)`，把 messages 用 HTTP POST 送到本機 Ollama（`http://localhost:11434/api/chat`），把模型的回覆拿回來。這一塊不碰工具、不碰迴圈，只求「送得出去、收得回來」。

## 觀念

- **API 呼叫的本質**：組一個 dict 當 body → 轉成 JSON 字串 → POST 出去 → 收到 JSON 字串 → 轉回 dict → 取 `result["message"]`。跟前端 `fetch` 打後端 API 完全同一件事，只是換了語言。
- **localhost URL 可以進 git**：`http://localhost:11434` 不是祕密——它指的是「執行者自己的電腦」，全世界寫出來都一樣，別人拿到也連不進你的機器。之後接雲端 API 時，**API key 才是祕密**，要用 `os.environ` 從環境變數讀，不能寫死在程式裡。

## 語法逐條（Python ↔ JS）

實際程式（`agent.py`）：

```python
import json
import urllib.request

MODEL = "qwen2.5:3b"
URL = "http://localhost:11434/api/chat"

def chat(msg):
    body = {"model": MODEL, "messages": msg, "stream": False}
    data = json.dumps(body).encode()
    req = urllib.request.Request(
        URL, data=data, headers={"Content-Type": "application/json"}
    )
    with urllib.request.urlopen(req) as resp:
        raw = resp.read()
        result = json.loads(raw)
        return result["message"]

if __name__ == "__main__":
    reply = chat([{"role": "user", "content": "hi"}])
    print(reply)
```

#### import：載入標準函式庫

Python
```python
import json
import urllib.request
```
JS
```js
// Node 內建 fetch，不用 import；舊時代要 require("http")
```
Python 標準函式庫（`json`、`urllib`）不用安裝、不用寫路徑，`import` 進來後用 `json.xxx` 呼叫。`urllib.request` 是內建的陽春版 fetch。

#### 全大寫變數：常數「慣例」

Python
```python
MODEL = "qwen2.5:3b"
```
JS
```js
const MODEL = "qwen2.5:3b"
```
Python 沒有 `const`，全大寫只是「別改我」的慣例，語言不強制；JS 的 `const` 是真的擋你重新賦值。

#### def：函式定義

Python
```python
def chat(msg):
    ...
```
JS
```js
function chat(msg) {
  ...
}
```
冒號＋縮排取代大括號——縮排在 Python 是語法的一部分，不只是排版。

#### dict：key-value 結構

Python
```python
body = {"model": MODEL, "messages": msg, "stream": False}
```
JS
```js
const body = { model: MODEL, messages: msg, stream: false }
```
兩個差異：Python 的 key **必須**加引號（忘了會被當變數名，直接 `NameError`）；布林是**大寫開頭**的 `True` / `False`（還有 `None` 對應 `null`）。

#### json.dumps / json.loads：dict ↔ JSON 字串

Python
```python
data = json.dumps(body)   # dict → JSON 字串
result = json.loads(raw)  # JSON 字串/bytes → dict
```
JS
```js
const data = JSON.stringify(body)
const result = JSON.parse(raw)
```
記法：dump**s** = dump to **s**tring、load**s** = load from **s**tring。`json.loads` 直接吃 bytes，不必先 decode。

#### .encode()：字串 → bytes

Python
```python
data = json.dumps(body).encode()
```
JS
```js
// fetch 幫你做掉了；手動版：
new TextEncoder().encode(str)
```
HTTP 線路上跑的是 bytes（位元組），Python 要你明講這步轉換；JS 的 `fetch` 把它藏起來了。

#### Request 物件與具名參數

Python
```python
req = urllib.request.Request(
    URL, data=data, headers={"Content-Type": "application/json"}
)
```
JS
```js
fetch(URL, { method: "POST", body: data, headers: {...} })
```
有 `data` 就自動變 POST。`data=data`、`headers=...` 是**具名參數**：呼叫時指定「這個值給哪個參數」，跟順序無關——JS 沒有這個語法，最接近的是傳 options object。

#### with：用完保證自動關

Python
```python
with urllib.request.urlopen(req) as resp:
    raw = resp.read()
```
JS
```js
try { ... } finally { resp.close() }
// 新版 JS 的 await using 同概念
```
進區塊時開啟資源、**離開時保證關閉**（出錯也會關），連線、檔案都適用。`resp.read()` 把回應整包讀成 bytes，對應 `await res.arrayBuffer()`。

#### 取 dict 的值：只有方括號

Python
```python
result["message"]
```
JS
```js
result.message        // 或 result["message"]
```
Python 的 dict **沒有點語法**；而且 key 不存在會直接丟 `KeyError`，不像 JS 安靜地回 `undefined`——錯誤更早炸出來，也更好找。

#### return 與預設回傳

Python
```python
return result["message"]
# 沒寫 return 的函式回 None
```
JS
```js
return result.message
// 沒寫 return 回 undefined
```

#### `if __name__ == "__main__":`：直接執行才跑

Python
```python
if __name__ == "__main__":
    reply = chat([{"role": "user", "content": "hi"}])
```
JS
```js
if (require.main === module) { ... }  // CommonJS；ESM 沒有內建等價物
```
被 `import` 時 `__name__` 是模組名，直接 `python3 agent.py` 跑才是 `"__main__"`——測試碼放這裡，別人 import 你的模組時不會誤觸。

## 踩過的坑 / 備註

- `json.dumps` 出來是**字串**，還要 `.encode()` 變 bytes 才能塞給 `urllib`——JS 的 fetch 把這兩步藏起來了，Python 要你自己走。
- dict 的 key 忘了加引號會直接 `NameError`（Python 以為那是變數名），跟 JS object 的寬鬆寫法不同。
